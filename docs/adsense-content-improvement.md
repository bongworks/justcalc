# 콘텐츠 품질 개선 분석 — 2026-10-01

대상: https://calc.bongworks.co.kr / 바로계산기. 목표는 AdSense 승인 가능성 개선, 계산 후 실제 판단에 도움이 되는 경험, 검색 유입과 재방문이다. 아래 진단은 운영 사이트와 코드의 관찰에 근거한 가설이며 Google의 내부 심사 이유를 확인한 결과는 아니다. AdSense 계정의 상세 심사 내역, Search Console, GA4에는 접근하지 않았다.

## 반영한 콘텐츠 방향

글 수나 분량을 일괄 늘리는 대신, 실제로 비교할 수 있는 네 가지 작업을 제공한다.

1. **자동차 비용:** 매달 필요한 현금과 보유 기간의 경제적 비용을 구별한다. 유지비, 할부 원금과 이자, 매각액을 중복 합산하지 않는 방법을 설명한다.
2. **대출 상환:** 같은 원금·금리·기간에서 세 상환 방식의 첫 달 부담, 마지막 달 금액, 총이자를 함께 비교한다. 만기일시의 낮은 월 납입액에 가려진 원금 상환을 드러낸다.
3. **저축 이자:** 처음부터 맡긴 목돈과 매월 말 추가한 돈의 이자 기간을 구별한다. 사이트의 월말 월복리 모델을 일반 단리 적금의 실제 견적으로 오인하지 않게 설명한다.
4. **할인 후 결제액:** 연속 할인, 쿠폰, 배송비와 단위당 가격을 구별해 표시 할인율보다 실제 지출을 비교한다.

홈 → 활용 가이드 → 관련 계산기 → 결과 해석 → 활용 가이드의 양방향 경로를 만든다. 모든 본문과 링크는 정적 HTML에 포함되어 JavaScript 없이도 읽을 수 있다. 계산 입력값·결과를 서버, URL, 저장소로 보내는 새 기능은 추가하지 않는다.

## 재심사 전 운영 확인

- 배포 후 실제 운영 URL에서 새 가이드·변경 제목·사이트맵이 보이는지 확인한다. 로컬 코드와 빌드만으로 운영 반영을 선언하지 않는다.
- 운영 주체와 문의 이메일의 수신 가능 여부, 개인정보·광고 고지가 실제 운영 설정과 맞는지 운영자가 확인한다. 검증하지 않은 운영자 신원이나 전문가 자격은 작성하지 않는다.
- 대표 페이지를 직접 읽고 예시 조건·금액·제외 비용이 이해되는지 확인한다. 최신 정책을 반영해야 하는 계산기는 일반 산술 검증만으로 공식 검토를 대신하지 않는다.
- 이후 AdSense에서 재심사를 요청한다. 페이지 수·글자 수·대기 일수·방문자 수에 임의의 승인 기준을 두지 않는다.

## 유입과 재방문을 확인하는 방법

현재 검색량과 트래픽을 확인하지 않았으므로 인기·전환 효과를 수치로 예측하지 않는다. 다음은 실행 후 관찰 계획이다.

| 목표 | 확인할 지표 | 다음 행동 |
| --- | --- | --- |
| 검색 노출 | Search Console의 페이지별 색인, 노출, 실제 검색어, 클릭률 | 관련 노출은 있으나 클릭이 적은 페이지의 제목과 설명을 검색 의도에 맞춰 수정 |
| 유용성 | 기존 값 없는 GA 이벤트의 계산 시작·성공·오류, 관련 도구 이동 | 필수 입력에서 이탈하거나 오류가 많은 도구의 입력 도움말과 모델을 개선 |
| 재방문 | 실제 GA 설정에서 제공하는 재방문 지표와 문의 피드백 | 반복 이용 목적이 확인된 도구의 비교 흐름과 모바일 UX 보강 |
| 콘텐츠 효과 | 새 가이드와 연결한 계산기의 유입 경로·계산 완료 변화 | 2~4주 관찰 구간을 시작점으로 삼되 표본이 부족하면 결론을 보류하고 더 관찰 |

변경 전후 기간, 광고 설정, 계절성과 캠페인 영향을 함께 기록한다. 비교 기간은 운영 관찰 계획일 뿐 Google의 승인 기준이 아니다. 분석 ID나 광고 활성화 설정은 이 작업으로 변경하지 않는다.

## 이번 범위 이후 필요한 정확성 개선

남은 계산기까지 완성도 높은 콘텐츠로 개선했다고 보지 않는다. 특히 다음은 추가 기능·계산 모델 검증의 우선 후보다.

- 연봉 실수령액: 적용 연도의 공식 요율·간이세액표와 지급 구조를 검증한 뒤 자동 모드 여부 결정.
- 적금: 일반 단리·납입일 모델을 별도로 제공하고 현행 월말 월복리와 구별.
- 경비 차감 시나리오: 일반 사업소득 원천징수용 도구는 과세대상 기준을 확인해 별도 설계. 이번에는 기능이 드러나도록 명칭 정정.
- 임대 수익률의 손실 0% 처리, 소득·자산 분모 0 비율, 실제 카드 할부 청구와 대출식의 차이: 결과 표현·모델 개선과 회귀 검증 필요.
- 운영 404 화면: 현재 기본 오류 화면 대신 정적 404 문서와 복구 링크를 제공하도록 호스팅 설정 검토.

## 분석 경계 검토

새 가이드가 홈페이지 방문으로 잘못 집계되지 않도록 기존 GA 페이지 허용 목록에 정적인 가이드 경로·제목만 추가했다. 전송 객체 생성, 캠페인 허용 목록, 쿼리·해시 제거 규칙은 그대로다. 가이드 5개 경로의 단위 회귀 테스트와 합성 GA ID 브라우저 테스트를 통해 페이지별 attribution과 입력 유사 URL 정보의 제외를 검증한 뒤 `check-no-input-leak`의 검토 해시를 갱신했다. 합성 브라우저 검증은 외부 요청을 차단하고 GA 라이브러리를 대체하며 실제 분석 서버로 전송하지 않는다.
