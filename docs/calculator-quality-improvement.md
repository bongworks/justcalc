## 반영한 기능

- 공통 입력: 유효한 원화 입력의 만·억·조 표시, 입력을 마친 뒤 천 단위 구분, 금액 더하기, 용도별 기간 프리셋.
- 공통 결과: 계산 당시 조건 표시·복사, 비교 기준 1개 저장 후 새 조건의 결과를 나란히 표시. 바뀐 항목 강조. 입력 편집은 현재 결과만 지우고 비교 기준은 유지하며, 초기화·계산기 이동은 모두 지운다.
- 입력값과 비교 기준은 React 메모리에만 존재한다. 저장소·URL·네트워크·분석 이벤트로 보내지 않는다.
- 대출 상환 비교: 거치 중 이자만 납부하고 남은 기간에 상환. 전체 기간·원금·일정 합계 보존. 대표 결과는 만기일시 대비 원금균등의 총이자 절감액.
- 적금: 단리/월복리, 월초/월말 선택. 화면 기본은 단리·월초이며 순수 함수의 기존 기본값은 호환성을 위해 유지.
- 예금: 단리/월복리 선택. 복리 적립: 월초/월말 선택과 세금 별도 표시.
- 카드 할부: 원리금균등 대출에서 원금균등 수수료 모델로 수정. 부분무이자는 처음 지정한 회차만 고객이 수수료를 부담하는 방식.
- 프리랜서: 총수입에 세율을 적용하고 입금액과 경비 지출 후 잔액을 구분.
- DTI: 기타 대출 연이자 포함. DSR·DTI·LTV·마진·가산율·임대 수익률의 분모 0은 ‘계산 불가’. 임대 손실을 음수로 보존.
- 대상 계산기 12개의 공식·예제·출처·검토일과 관련 활용 가이드를 계산 동작에 맞춰 갱신.

## 검증

- 기존 474개 테스트를 기준으로 신규 기능·수치 오류의 실패 테스트를 먼저 확인했다.
- 단위·컴포넌트: 47개 파일, 542개 통과.
- 데스크톱·375px 모바일 브라우저: 545개 통과, 13개 환경별/별도 분석 모드 테스트 skip.
- TypeScript를 포함한 프로덕션 빌드, ESLint, 카탈로그, 입력값 비전송 검사 통과.
- 103개 정적 공개 페이지의 canonical·내부 링크·사이트맵·robots·자산 검사 통과.
- 독립 코드 검토의 소수 지수 입력 확장 문제를 회귀 테스트로 재현하고 지수 표기 fallback으로 수정했다.
- 브라우저에서 실제 적금 계산과 조건별 비교 표를 직접 확인했다.

## 남아 있는 범위

로컬 `out/`은 GA·AdSense ID를 비운 검증 빌드다. 운영 배포는 `release-X.Y.Z` 태그를 통해 수행하며, 배포 및 GitHub Release 발행 결과는 `Build and deploy` 워크플로에서 확인한다.

급여·복지의 법정 요율/간이세액표 자동 조회, 부동산 중개보수의 거래 유형별 자동 요율, 전기요금 누진구간 고지액 계산은 이번에 구현하지 않았다. 해당 계산기는 기존 수동 입력 범위를 유지한다. 카드 수수료와 예적금은 월 단위 근사이며 실제 결제일·납입일의 일할 계산은 지원하지 않는다. 대출 변동금리·중도상환 역시 별도 확장 대상이다.
